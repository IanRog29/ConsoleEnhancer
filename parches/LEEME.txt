Source code patches for third-party code, not binaries. Optional. Each patch keeps the license of the code it changes, and each change
carries its date in a comment, as section 5 of the GPL asks.

PrismaNr ("DLSS 5" inside the engine, C++) is not a patch: its source is in src\PrismaNr (since 1.3). It is built with NVIDIA's two
public NGX headers (scripts\descargar_cabeceras_ngx.ps1, not in git) and loads the unofficial DLL in a way the NVIDIA RTX SDKs license
does not allow (see THIRD-PARTY.md). Without PrismaNr.dll the engine works the same (src\Motor\Engine\EngineDlss5.cs only uses it if
it is there).
